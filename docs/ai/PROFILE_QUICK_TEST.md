##### 修改密码
```

Request: {
  "old_password": "oldpass",
  "new_password": "newpass"
}

  "message": "密码修改成功"
}
```

### 使用 curl 测试

```bash
# 1. 登录获取 token
TOKEN=$(curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"testpass"}' \
  | jq -r '.access_token')

# 2. 获取资料
curl -X GET http://localhost:8000/api/profile \
  -H "Authorization: Bearer $TOKEN"

# 3. 更新资料
curl -X PUT http://localhost:8000/api/profile \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"nickname":"小明","gender":"male","age":12}'

# 4. 修改密码
curl -X POST http://localhost:8000/api/profile/change-password \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"old_password":"testpass","new_password":"newpass123"}'
```

## 常见问题排查

### 问题 1: 页面显示空白
**可能原因**: 
- 后端服务未启动
- API 请求失败

**排查步骤**:
1. 检查浏览器控制台是否有错误
2. 检查 Network 标签中的 API 请求状态
3. 确认后端服务正在运行

### 问题 2: 保存后数据没有更新
**可能原因**:
- API 请求失败
- 数据库连接问题

**排查步骤**:
1. 查看浏览器控制台的错误信息
2. 查看后端日志
3. 检查数据库文件是否存在

### 问题 3: 修改密码后无法登录
**可能原因**:
- 使用了旧密码
- 新密码输入错误

**排查步骤**:
1. 确认使用的是新密码
2. 检查密码是否正确（注意大小写）
3. 如果确实忘记，需要重置密码

### 问题 4: 表单验证不生效
**可能原因**:
- 前端代码错误
- Element Plus 版本问题

**排查步骤**:
1. 检查浏览器控制台是否有错误
2. 确认 Element Plus 正确安装
3. 查看表单验证规则是否正确定义
