## 🐛 常见问题排查

### 问题 1: 页面跳动

**现象**: 加载历史消息后，页面突然跳到顶部或底部

**排查**:
1. 检查 `previousScrollHeight` 是否正确记录
2. 检查 `scrollDiff` 计算是否正确
3. 确认 `nextTick` 后再调整滚动位置

**解决**:
```javascript
// 记录高度
previousScrollHeight.value = messagesContainer.value.scrollHeight

// 加载消息...

// 调整位置
await nextTick()
const scrollDiff = messagesContainer.value.scrollHeight - previousScrollHeight.value
messagesContainer.value.scrollTop = scrollDiff
```

### 问题 2: 重复加载

**现象**: 滚动时不断触发加载，消息重复

**排查**:
1. 检查 `loadingMore` 标志是否正常
2. 检查 `hasMore` 是否正确更新
3. 查看网络请求是否重复

**解决**:
```javascript
if (loadingMore.value || !hasMore.value) return
```

### 问题 3: 不触发加载

**现象**: 滚动到顶部，不加载历史消息

**排查**:
1. 检查 `@scroll` 事件是否绑定
2. 检查 `scrollTop < 100` 条件
3. 确认 `hasMore` 为 true
4. 确认 `conversationId` 存在

**解决**:
```javascript
// 确保滚动容器有 @scroll 事件
<div class="messages-container" ref="messagesContainer" @scroll="handleScroll">
```

### 问题 4: 输入框不聚焦

**现象**: 进入页面后，输入框没有自动聚焦

**排查**:
1. 检查选择器是否正确
2. 确认元素已渲染
3. 使用 `nextTick` 等待渲染

**解决**:
```javascript
nextTick(() => {
  const inputElement = document.querySelector('.message-input textarea')
  if (inputElement) {
    inputElement.focus()
  }
})
```

### 问题 5: API 返回错误

**现象**: 控制台显示 404 或其他错误

**排查**:
1. 检查 API 路径是否正确
2. 确认 `conversationId` 有效
3. 检查用户权限
4. 查看后端日志

**解决**:
```bash
# 检查后端日志
tail -f backend/logs/app.log

# 测试 API
curl -H "Authorization: Bearer $TOKEN" \
  "http://localhost:8000/api/chat/conversations/1/messages?offset=0&limit=10"
```
