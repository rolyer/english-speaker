## 🚀 使用方法

### 访问个人资料页面
1. 登录系统
2. 点击右上角用户头像
3. 选择"个人资料"

2. 输入新密码
3. 确认新密码
4. 点击"修改密码"
5. 系统自动退出，使用新密码登录

## 📊 API 端点

### 1. 获取用户资料
```http
GET /api/profile
Authorization: Bearer {token}

Response 200:
{
  "id": 1,
  "username": "user123",
  "email": "user@example.com",
  "nickname": "小明",
  "gender": "male",
  "age": 12,
  "created_at": "2025-01-01T00:00:00"
}
```

### 2. 更新用户资料
```http
PUT /api/profile
Authorization: Bearer {token}
Content-Type: application/json

Request:
{
  "nickname": "小明",
  "gender": "male",
  "age": 12
}

Response 200:
{
  "id": 1,
  "username": "user123",
  "email": "user@example.com",
  "nickname": "小明",
  "gender": "male",
  "age": 12,
  "created_at": "2025-01-01T00:00:00"
}
```

### 3. 修改密码
```http
POST /api/profile/change-password
Authorization: Bearer {token}
Content-Type: application/json

Request:
{
  "old_password": "oldpass123",
  "new_password": "newpass456"
}

Response 200:
{
  "message": "密码修改成功"
}
```
