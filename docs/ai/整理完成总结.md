## 📝 维护建议

### 日常维护
1. **添加新文档时**
   - 核心文档放在 `docs/` 根目录
   - AI 生成的文档放在 `docs/ai/`
   - 更新相应的 README.md 索引

2. **定期清理**
   - 每月检查一次，归档过时文档
   - 合并重复或相似的文档
   - 更新索引文件

3. **版本控制**
   - 重要文档变更要提交 Git
   - 在 commit message 中说明变更

### 文档命名规范
- `*_FIX.md` → 问题修复
- `*_FEATURE.md` → 功能实现
- `*_SETUP.md` → 配置设置
- `*_SUMMARY.md` → 总结文档
- `*_DEBUG.md` → 调试文档
- `QUICK_*.md` → 快速指南
